 TLD Logistics — خروجی کامل پروژه
 تاریخ: 2026/11/13
========================================================

این آرشیو شامل تمام سورس‌کد، اسکیمای دیتابیس، وب مدیریتی،
فونت‌ها، مستندات و فایل نصبی اندروید است.

--------------------------------------------------------
 ۱) ساختار پوشه‌ها
--------------------------------------------------------

src/            اپ اصلی (React 19 + TypeScript + PWA)
  screens/      ۵۹ صفحه (راننده، صاحب بار، عملیات)
  components/   کامپوننت‌های مشترک
  services/     لایه اتصال به Supabase
  context/      Auth / Language / Logistics
  i18n/         دیکشنری سه‌زبانه (fa / en / tr)

admin/          وب مدیریتی مستقل (React + Vite)
  src/pages/    نمای کلی، احراز هویت، محموله‌ها، مالی،
                داوری، ماژول‌ها، تنظیمات، گزارش فعالیت

supabase/       دیتابیس
  migrations/   ۸ فایل SQL (به ترتیب تاریخ اجرا شوند)
  functions/    ۵ Edge Function (Deno)
  apply_now.sql اجرای یکجای دو migration آخر
  demo-seed.sql داده نمایشی

public/         فونت‌های self-host، آیکون‌ها، لوگو
android/        پروژه Capacitor اندروید
.github/        workflow ساخت APK و CI
apk/            فایل نصبی آماده اندروید

--------------------------------------------------------
 ۲) راه‌اندازی اپ اصلی
--------------------------------------------------------

  npm install
  cp .env.example .env      ← مقادیر Supabase را جایگزین کن
  npm run dev               → http://localhost:3000

--------------------------------------------------------
 ۳) وب مدیریتی
--------------------------------------------------------

  npm run admin:dev         → http://localhost:3100
  npm run admin:build       → خروجی در dist-admin/

  ورود ادمین:
    ایمیل: admin@tldlogistics.ir
    رمز  : ← عمداً در مستندات نوشته نمی‌شود. رمز را از مدیر پروژه
             بگیرید یا در داشبورد Supabase (Authentication) بازنشانی کنید.

  ⚠️ دسترسی ادمین در سمت سرور با تابع is_admin() و RLS
     کنترل می‌شود؛ کلید service_role هرگز در کلاینت نیست.

--------------------------------------------------------
 ۶) فایل نصبی اندروید
--------------------------------------------------------

  apk/TLD-Logistics-demo.apk   (build debug، ۶ مگابایت)

  ساخت مجدد APK:
    build روی GitHub Actions انجام می‌شود
    (.github/workflows/android.yml)
    یا محلی:  npm run build && npx cap sync android
              سپس: cd android && gradlew assembleDebug

--------------------------------------------------------
 ۷) نکات امنیتی
--------------------------------------------------------

  • فایل .env عمداً در این آرشیو نیست (حاوی کلیدها).
    از .env.example کپی بگیر.
  • کلید service_role فقط در Edge Functions استفاده می‌شود.
  • تمام جداول RLS دارند؛ هر کاربر فقط داده خودش را می‌بیند.
  • رمز دیتابیس در هیچ فایلی ذخیره نشده است.
